# T4 按 Go/No-Go 门槛验证 P0 使用闭环

- 父任务：`11-24-personal-dashboard`，执行顺序第 5 项（序号 4）
- 阶段 / 优先级：阶段 2 验证门槛 / P0
- 前置：T2、T3；**本项解锁或终止阶段 3/4 全部任务**
- 状态：planning（仅登记，未 start）

## 目标

用真实使用数据验证「看板是否真的改变了行为」，对抗个人自用场景最高频失败模式「看板变墙纸」。

## 判定标准

P0 上线两周后：① 每周主动打开次数 ≥2；② 至少一次因看板改变了当天动作。两条同时满足为 **Go**，解锁 T5–T11；否则为 **No-Go**，停止后续投入，退回周报导出脚本或直接砍掉看板。

## 验收标准（可测试）

产出明确的 Go / No-Go 结论及依据记录（打开次数、可复述的行为改变案例）；并据此显式解锁或终止后续任务。

## 不做的事

不用「页面好看」「数据齐全」等不可验收描述代替判定；不因已投入成本而放宽门槛。
