# README 美化与内容校正

## 1. 背景

`README.md` 当前 237 行，但「功能」章节为 30 余条超长单行列表（单条最长超过 2000 字），
可读性差；技术栈版本、项目结构、方法数量、构建产物体积等信息与实际代码不一致。
本次仅修改文档，不改动任何代码与运行行为。

## 2. 目标

1. **格式美化**：增加目录；功能清单按业务域拆分为二级小节；长条目拆分为「加粗要点 + 说明句/子项」，禁止单行超长段落。
2. **内容校正**：以仓库实际文件为真相源，修正版本号、项目结构、方法数量、产物体积、功能描述偏差。
3. **信息不丢失**：现有 README 承载的细节需要保留（`docs/功能说明.md` 尚未覆盖仓库统计、状态看板、仓库筛选器、检查更新等模块），压缩时不得删除唯一记录的事实。

| 版本号 | `wails.json` → `info.productVersion` = 1.15.0 |

- [ ] 技术栈表版本与 `frontend/package.json`、`go.mod` 一致（Vue ~3.5.42、Element Plus 2.14.5、Pinia ~4.1.0、Vue Router ~5.4.0、Vite ^8.0.10）。
