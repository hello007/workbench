# PRD：CHANGELOG 补齐 v1.3.0+ 版本记录

## 背景

CHANGELOG.md 的 `[Unreleased]` 段停留在 2026 年 5 月 v1.0.x 时代的旧内容（文件预览编辑/自定义快捷键等），此后 v1.3.0 → v1.8.0 的所有版本（AI 功能全量、AI 开发辅助、全局状态看板、AI 对话、平台加固等）均未记录，版本与变更追溯断档。

## 需求

1. 梳理 `git log`（tag 与提交）+ `docs/路线图.md` 里程碑表，还原 v1.3.0 至 v1.8.0 各版本变更。
2. 按 Keep a Changelog 格式（Added/Changed/Fixed 分节）补齐各版本记录。
3. 现有 `[Unreleased]` 旧内容归类到对应历史版本（或确认其已随 v1.0.x 发版则移入对应版本节）。
4. 版本日期与里程碑表对齐（以 git tag 日期为准）。

## 验收

- [ ] v1.3.0 → v1.8.0 每个已发版本在 CHANGELOG.md 均有小节，内容与实际提交吻合。
- [ ] `[Unreleased]` 段为空或仅含未发版内容，无 5 月遗留。
- [ ] 版本日期与 git tag 一致。

## 非目标

- 不修改 v1.0.x 早期已正确记录的条目。
