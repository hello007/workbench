# PRD：xlsx 漏洞上游调研与依赖处置

## 背景

npm audit 已知接受风险：前端依赖 `xlsx`（SheetJS）存在无官方补丁的安全漏洞，此前留档接受。需调研上游是否已出修复版本，评估升级或替换可行性并留档结论。

## 需求

1. 确认当前 `xlsx` 依赖版本、引入位置（哪个前端功能使用）与具体漏洞编号/严重级别。
2. 调研 SheetJS 官方分发渠道（npm registry 停更后需从 cdn.sheetjs.com 安装）是否已有修复版本。
3. 评估处置选项：升级到官方修复版 / 换用替代库（如 exceljs）/ 维持接受，给出结论与理由。
4. 结论留档至 `docs/spec/security-scan.md`（更新既有留档段落）；若执行升级，同步重跑 `npm audit` 验证并更新 CLAUDE.md 关键规则中相关描述。

## 验收

- [ ] xlsx 当前版本、使用位置、漏洞清单调查结论写入 security-scan.md。
- [ ] 处置决策明确（升级/替换/维持）且有依据；若可修复则漏洞清零。

## 非目标

- 不做超出 xlsx 范围的其他依赖升级。
