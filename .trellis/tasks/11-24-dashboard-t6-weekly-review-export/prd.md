# T6 实现周/月回顾自动导出

- 父任务：`11-24-personal-dashboard`，执行顺序第 7 项（序号 6）
- 阶段 / 优先级：阶段 3 P1 闭环 / P1
- 前置：T5；与 T7 可并行
- 状态：planning（仅登记，未 start）

## 目标

形成反馈闭环：一个月才看一次的不是看板、是报告，故需可回看、可导出的报告形态，避免看板沦为墙纸。

## 复用点

`ExportAiTaskHistoryCSV` / `ExportAiTaskHistoryMarkdown`、T1 的聚合结果、T5 的活动数据。摘要内容：产出节奏、AI 成本、待办积压、功能使用；导出 Markdown / CSV。

## 验收标准（可测试）

能自动生成并导出一份回顾摘要，摘要中每项数据均带来源与口径标注；导出文件可被外部工具打开且中文不乱码。

## 不做的事

不做邮件/推送发送，不做云端存储，不引入定时任务框架。
