# B 方案 PR2：前端三落点确认弹窗与结果明细

父任务：`10-31-b`（方案与决策见父任务 prd.md）

## 范围

1. 拆分确认弹窗改为三选项：素材库缓存目录（默认）/ 源文件所在目录 / **就地替换（删除源文件）**。
2. replace 选项附不可逆强确认文案：「原始文件将被删除，单页文件保存于 `<源名主干>/` 目录，并会作为独立素材进入素材库」，需勾选或二次确认。
3. 批量拆分入口同口径（库级「拆分全部 PPT」）；两入口共用同一弹窗组件与确认逻辑。
4. 结果明细区分三种收尾：已删除源（成功）/ 已保留源（拆分失败）/ 已回滚（取消）；批量汇总增加对应计数。
5. replace 成功后触发 `refreshDataAfterMutation`（或增量重扫）使新素材出现在素材库。
6. 同步 `frontend/wailsjs/go/main/App.js`、`App.d.ts`（落点参数签名变化）；如新增具名类型需补 `models.ts` 别名。
7. 同步 `frontend/src/test/wails-mock-defaults.js`（E2E mock 单一数据源）。

## 验收

- [x] 三选项可切换，默认缓存目录；replace 未勾选强确认时提交按钮禁用。
- [x] 单文件与批量两条链路均传对落点参数（单测断言调用参数）。
- [x] 结果明细三类计数与文案正确；失败文件列出相对路径与原因。
- [x] replace 成功后素材库出现单页素材（刷新链已接）。
- [x] 既有拆分单测/组件用例全绿；前端覆盖率 ≥70%（实测 85.93%）。

## 注意

- 视觉守 `docs/spec/frontend-visual-conventions.md`；禁新增裸色值。
