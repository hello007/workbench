# 临时会话记忆：代码套路

> agent 在会话中总结出的本仓代码套路，属临时会话记忆（`temp-memory/`）——**不是长期沉淀**。
> 每条都有出口：确认成立且该长期约束的**升级到 `conventions/`**，过时或不再适用的删除。
> 写新代码前读，照抄现有写法而不是发明新的。通用语言/框架规范去 `conventions/coding-*.md`。
> **积压提醒**：本文超过 8 条套路时，agent 须在回复中提醒用户判断哪些升级到 conventions、哪些可删，不自行处置。

## 核心代码模式
 
*暂无套路，待积累。记录格式示例：`- **[代码模式名称]**：[说明在何种场景下，推荐使用何种标准规范写法，避免何种典型错误]`*

## 更新时机

发现一个「本来会写错、看了现有代码才写对」的套路时，追加一条。

追加后数一下套路条数（`##` 小节数，不含本节）：**超过 8 条**就在本次回复里提醒用户判断哪些升级到 `conventions/`、哪些可删——agent 不自行升级也不自行删除。
