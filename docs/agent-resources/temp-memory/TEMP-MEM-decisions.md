# 临时会话记忆：决策

> agent 在会话中识别到的技术决策及**理由**，属临时会话记忆（`temp-memory/`）——**不是长期沉淀**。
> 每条都有出口：有长期价值的**升级为 ADR**（`docs/agent-resources/adrs/`），其余判断后删除。
> 改动涉及既有设计前读这里，避免推翻一个当初有理由的选择。

格式：`日期 | 决策 | 理由 | 影响面`。重大架构决策直接走 ADR 正式流程，不在这里过渡。

**积压提醒**：本表超过 15 条时，agent 须在回复中提醒用户判断哪些升级为 ADR、哪些可删，不自行处置。

| 日期 | 决策 | 理由 | 影响面 |
|------|------|------|--------|

*暂无决策。登记格式示例：`| YYYY-MM | 决策内容 | 选择理由 | 影响的模块/范围 |`*

选了 A 没选 B 且理由不写下来下次会重新纠结时，追加一行。重大架构决策不走这里，直接建 ADR。
