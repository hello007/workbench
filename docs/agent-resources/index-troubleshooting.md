## 审核规则

- 每条排障条目有独立的审核周期（默认 6 个月），到期后需重新验证解法是否仍然有效
- 永久解法实施后（如修复了根因、升级了版本），直接删除对应条目
- agent 在加载索引时如发现过期条目，应提醒处理
