# 文档治理规范

> 本文描述项目正式文档的治理规范：目录结构、入口清单、归属判定、索引维护。
> **内容易腐**：引用前先核对当前文档目录。

## 文档库位置

- 正式文档目录：`docs/`（全中文）
- 深度规范沉淀：`docs/spec/`
- 项目长期记忆：`docs/memory/`
- agent 参考文档：`docs/agent-resources/`

## 目录结构

```
docs/
├── 快速入门.md / 功能说明.md        # 使用者文档（安装、功能、FAQ）
├── 开发工作流.md / 测试策略.md      # 开发者文档（构建、测试）
├── 部署说明.md / 开发规范.md        # 部署与规范
├── 架构设计.md / API参考.md         # 架构与接口（API 参考 = Wails 绑定方法清单）
├── 贡献指南.md / 常见问题.md / 路线图.md
├── spec/                            # 跨层契约与深度规范（README.md 为分流规则与索引）
├── memory/                          # 项目长期记忆（MEMORY.md 为索引，hook 自动加载）
├── agent-resources/                 # agent 工程规范（本体系）
├── archive/                         # 历史归档（plans / superpowers / 已归档专题）
├── research/                        # 调研资料（按日期命名）
└── 原始需求/                        # 原始需求说明书
```

## 归属判定

| 内容性质 | 归属 |
|----------|------|
| 面向使用者的功能/安装/FAQ | `docs/` 对应篇目 |
| 跨层契约、签名同步规则、踩坑机理（为什么/怎么踩的） | `docs/spec/<topic>.md` |
| 每次会话必知的钩子级规则（禁令、单点函数、错误码） | 仓根 `AGENTS.md`「关键规则」行内 |
| 跨会话项目事实/偏好 | `docs/memory/` |
| agent 工程规范（通用规则/剧本/参考） | `docs/agent-resources/` |

两级分流细则以仓根 `AGENTS.md`「关键规则与规范沉淀」节为准（行内 ≤250/≤350 字符上限、超限下沉 `docs/spec/`）。

## 治理规则

- 新增模块/能力 → 新增或更新对应 `docs/` 篇目，并确认 README.md 是否需更新
- 修改对外接口 / 配置项 / 错误码 → 同步更新对应文档与 `docs/API参考.md`
- 项目功能完成后 → 确认是否更新 README.md（文档语言约定要求）
- `docs/spec/` 条目须在 `docs/spec/README.md` 登记索引；`docs/memory/` 条目须在 `docs/memory/MEMORY.md` 登记一行
- 废弃文档删除入口清单行，内容归档至 `docs/archive/` 或删除由用户决定
