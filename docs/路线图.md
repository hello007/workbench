# WorkBench 发展路线图

本文档规划了 WorkBench 项目的未来发展方向和功能计划。

## Phase 2 功能（计划中）

### Git 增强功能

- [x] **Git 提交和推送** ✅ 已实现
  - [x] 选择文件进行暂存（`Commit` 支持选择性 pathspec 提交,未勾选文件保持未提交）
  - [x] 编辑提交信息
  - [x] 推送到远程仓库（`Push`,无上游时确认 `--set-upstream`）
  - [ ] 查看推送结果（推送返回输出无独立结果面板,边缘项）

- [x] **分支管理**（查看+切换+增删改已实现）
  - [x] 查看所有分支（本地和远程,`GetBranches`）
  - [x] 创建新分支（`CreateBranch`,从当前 HEAD,`git branch <name>`）
  - [x] 切换分支（`CheckoutBranch`,含远程分支）
  - [x] 删除分支（`DeleteBranch`,`-d` 失败二次确认走 `-D` 强删,当前分支禁删）
  - [x] 重命名分支（`RenameBranch`,`git branch -m <old> <new>`,仅本地不触远程）

- [x] **暂存区和 Diff 查看**（diff+丢弃+单文件暂存已实现）
  - [x] 查看未暂存的更改（`GetLocalChanges`,`--porcelain -z --untracked-files=all`）
  - [x] 查看已暂存的更改（数据层返回 `Staged` 字段;前端单表分组:未暂存组上/已暂存组下,`Staged` 字段驱动）
  - [x] 行级 diff 对比（`GetDiff` 双栏对照,已跟踪对比 HEAD,未跟踪展示新增全文）
  - [x] 暂存/取消暂存单个文件（`StageFiles`/`UnstageFiles`,行级 +/- 按钮 + 批量「暂存选中/取消暂存选中」并入「更多」下拉;`git restore --staged` 统一命令通配已跟踪/未跟踪）
  - [x] 丢弃本地更改（`DiscardChanges`）

- [ ] **提交历史增强**（分页+详情+commit 间 diff 已实现,搜索/过滤未实现）
  - [x] 分页查看提交历史（`GetCommitHistory` limit/offset 分页,go-git Log）
  - [x] 查看提交详情（作者/邮箱/SHA/消息/DateTime/Files 文件列表均已返回,详情面板展示完整 SHA/邮箱/时间/变更文件）
  - [x] 查看提交之间的 diff（`GetRangeDiff` 两 commit 区间 diff + `GetCommitFileDiff` 单 commit 单文件 diff,root commit 对比空树全增,二进制兜底;前端列表勾选两个提交对比 + 文件 tag 弹窗 diff）
  - [x] 搜索提交历史（`GetCommitHistory` 加 `model.CommitFilter` 参数，关键词匹配提交消息，服务端迭代覆盖 >500 条）
  - [x] 按作者/日期/文件过滤（作者 Name+Email 子串、日期区间 Since/Until 下推 go-git LogOptions、文件路径 PathFilter 子串；前端 CommitHistory.vue 头部过滤条件行 + 防抖服务端触发）

### Git 高级操作

- [x] **合并和变基** ✅ 已交付
  - 分支合并（`git merge` 支持 ff/no-ff/squash 三策略，合并前校验工作区干净与非 detached HEAD）
  - 变基操作（`git rebase <branch>`，中途冲突支持 `--continue`/`--abort`/`--skip`）
  - Cherry-pick 拣选（`git cherry-pick <sha>` 单提交拣选，冲突支持 `--continue`/`--abort`）
  - Pull --rebase 整合（`Pull` 增 `useRebase` 参数，默认 false 保持原行为，`git pull --rebase`）
  - 冲突解决辅助（冲突文件列表 `git diff --name-only --diff-filter=U` + 标记已解决 `git add` + continue/abort，不做内置三方合并编辑器）
  - 合并策略选择（ff/no-ff/squash 三选一）

- [x] **标签管理**
  - 查看所有标签（名称 / 类型 lightweight|annotated / SHA / message / date） ✅
  - 创建轻量标签和注释标签（仅钉 HEAD，`-a -m`） ✅
  - 删除标签（本地 `git tag -d`） ✅
  - 推送标签到远程（单个 `git push origin <tag>` + 推送全部 `git push --tags`） ✅

- [x] **远程仓库管理**
  - 添加/删除远程仓库（`git remote add` / `git remote remove`） ✅
  - 查看远程仓库信息（名称 + URL） ✅
  - Fetch 远程更新（`git fetch [<remote>]`，可选 `--prune`） ✅
  - 设置远程跟踪分支（当前分支 + 选 remote，`git branch --set-upstream-to`） ✅

- [x] **Submodule 支持** ✅ 已实现
  - 查看 Submodule 列表（`git submodule status` + `git status --porcelain=2` 双命令融合，按 path 关联） ✅
  - Submodule 状态显示（四色标签：灰=未初始化、绿=干净、橙=已修改/SHA 未同步、红=冲突；detached HEAD 警告标记） ✅
  - 初始化 Submodule（`git submodule update --init`） ✅
  - 更新 Submodule（checkout/merge/rebase/remote 四模式 + recursive + init 开关，支持全量与单行） ✅
  - 添加 Submodule（`git submodule add [-b branch] <url> <path>`） ✅
  - 删除 Submodule（deinit -f + git rm -f + 清理 `.git/modules/<name>` 三步） ✅
  - detached HEAD 切换跟踪分支（读 `.gitmodules` branch 配置，`git -C <path> checkout <branch>`） ✅
