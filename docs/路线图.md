# WorkBench 发展路线图

本文档规划了 WorkBench 项目的未来发展方向和功能计划。

## Phase 2 功能（计划中）

### Git 增强功能

- [x] **Git 提交和推送** ✅ 已实现
  - [x] 选择文件进行暂存（`Commit` 支持选择性 pathspec 提交,未勾选文件保持未提交）
  - [x] 编辑提交信息
  - [x] 推送到远程仓库（`Push`,无上游时确认 `--set-upstream`）
  - [ ] 查看推送结果（推送返回输出无独立结果面板,边缘项）

- [ ] **分支管理**（查看+切换已实现,增删改未实现）
  - [x] 查看所有分支（本地和远程,`GetBranches`）
  - [ ] 创建新分支（无 `CreateBranch`）
  - [x] 切换分支（`CheckoutBranch`,含远程分支）
  - [ ] 删除分支（无 `DeleteBranch`）
  - [ ] 重命名分支（无 `RenameBranch`）

- [ ] **暂存区和 Diff 查看**（diff+丢弃已实现,单文件暂存未实现）
  - [x] 查看未暂存的更改（`GetLocalChanges`,`--porcelain -z --untracked-files=all`）
  - [x] 查看已暂存的更改（数据层返回 `Staged` 字段区分;前端变动面板单区展示,未分已暂存/未暂存双栏）
  - [x] 行级 diff 对比（`GetDiff` 双栏对照,已跟踪对比 HEAD,未跟踪展示新增全文）
  - [ ] 暂存/取消暂存单个文件（无 `Stage`/`Unstage`）
  - [x] 丢弃本地更改（`DiscardChanges`）

- [ ] **提交历史增强**（分页+详情部分实现,搜索/过滤/commit 间 diff 未实现）
  - [x] 分页查看提交历史（`GetCommitHistory` limit/offset 分页,go-git Log）
  - [ ] 查看提交详情（作者/邮箱/SHA/消息已返回;日期 When 与单条文件列表未实现）
  - [ ] 查看提交之间的 diff
  - [ ] 搜索提交历史
  - [ ] 按作者/日期/文件过滤
