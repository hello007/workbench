# WorkBench

> 开发者工作台 —— 把目录管理、文件浏览与预览、Git 操作、素材索引、AI 辅助和内置终端收进同一个桌面应用。

WorkBench 基于 **Wails + Vue 3** 构建，前后端同仓：Go 负责文件系统、Git、终端、素材索引与本地 HTTP 服务，Vue 3 负责界面与交互。同一份二进制既可作为 Windows / Linux 桌面应用运行，也可开启浏览器访问模式，供本机其他浏览器或远程设备使用。

- **版本**：以 `wails.json` 的 `info.productVersion` 为准
- **交付形态**：Windows / Linux 桌面可执行文件，另支持 `--serve` 无头浏览器访问模式

## 功能特性

> 以下为能力概览；逐项操作说明见 [功能说明](docs/功能说明.md)。

### 工作区与文件

- **三列布局** — 工作目录树 | 文件树 | 操作面板，信息层次清晰；左侧活动栏可切换工作目录、AI 功能、AI 对话、工具箱、素材管理、状态看板、仓库统计、分支对比、临时待办等一级面板。
- **工作目录管理** — 管理多个工作目录，支持添加、删除（`Delete`）、重命名（`F2`）、设为默认、复制路径、右键在资源管理器 / VSCode / Warp / Obsidian 中打开，以及批量更新仓库。
- **文件树浏览** — 树形展示目录结构，文件夹优先排序；右键菜单支持点击任意位置自动关闭，空白区域右键可新建文件 / 文件夹。
  - 大目录（单层超过 2000 项）自动截断并以哨兵行提示；工具栏筛选框支持目录内按名筛选，可定位截断层之外的文件（补齐扁平 `node_modules` 盲区）。
  - 普通树与聚合树的展开状态分别持久化，互不污染。
- **聚合视图（收藏目录统一浏览）** — 文件树工具栏一键在「目录树 ⇄ 聚合视图」间切换：虚拟根下平铺全部**目录类型**收藏，免去在多个工作目录之间反复切换即可统一展开、预览、编辑与新建 / 重命名 / 删除 / 复制粘贴。
  - 复用既有绝对路径链路，支持目录内按名筛选（作用域为点击的目录）。
  - 右键「设为工作目录」可将该目录一键提升并切换；选择工作目录会自动退出聚合，聚合仅由工具栏按钮进入。
  - 收藏项失效（已删除 / 已移动 / 无权限 / 网络盘不可达）时节点标灰加删除线，并提示可右键移除收藏。
- **文件操作** — 新建、重命名、删除、预览，支持在资源管理器 / VSCode / Warp / Obsidian 中打开。
  - 「拷贝到」支持自定义目标文件名（默认与原名一致，同名冲突自动加 `(1)`），拷贝时自动去除目标只读属性。
- **仓库筛选器** — 文件树工具栏按钮或空白区右键菜单打开弹窗，扫描当前工作目录下所有 Git 仓库：
  - 支持工作目录切换、按仓库名 / 路径搜索、标签 OR 筛选，以及「已编辑 / 未编辑」双 Tab 分类（有标签即视为已编辑）。
  - 左栏为虚拟滚动列表（`@vueuse/core` `useVirtualList`）；右栏可编辑自定义简述（防抖 800ms 自动保存）与标签（增删即时保存），并展示 README 摘要。
  - 失效仓库灰显并支持一键清理；点击条目跳转并自动展开文件树定位目标节点（跨工作目录时先切换再定位）。

### 文件预览与编辑

- **按文件类型直接预览** — 在操作面板内按类型渲染，无需外部程序：

| 类型 | 渲染方式 | 说明 |
| ---- | ---- | ---- |
| 图片（jpg / jpeg / png / bmp / gif / webp） | base64 内嵌 | 支持缩放 |
| 文本 / 代码（txt、json、sql、md 及各类源码） | CodeMirror 6 只读高亮 | 行号、折叠、虚拟滚动；GBK 自动转 UTF-8 显示 |
| Markdown | markdown-it 渲染 | 关闭原始 HTML 防 XSS；代码高亮按主题切换 |
| Word（`.docx`） | docx-preview 内嵌渲染 | 只读 |
| Excel（`.xlsx` / `.xls` / `.csv`） | SheetJS 解析为只读表格 | 多 Sheet 标签页 |
| PowerPoint（`.pptx` / `.ppsx`） | 本机 PowerPoint / WPS COM 转 PDF 后复用 pdfjs viewer | 翻页 / 缩放 / 搜索 / 缩略图，高保真 |
| PDF | pdfjs 官方 viewer（iframe 内嵌） | 支持翻页 / 缩放 / 搜索 / 缩略图 |
| HTML（`.html` / `.htm`） | iframe `srcdoc` + `sandbox="allow-scripts"` | 默认渲染效果，可切源码态编辑 |

- **PPTX 预览缓存** — 转换产物落 `data/pptx_preview_pdf/`：源文件 `mtime + size` 失效、LRU 上限 512MB 淘汰最旧、同文件在途转换防抖共享、瞬态失败重试一次；二次预览命中缓存无转换延迟。未检测到 PowerPoint / WPS 或转换失败时保留降级提示，并提供「用默认程序打开」。
- **PDF 同源字节服务** — 主页面不引入 pdfjs 库，改由 iframe 独立 browsing context 加载内嵌 viewer；后端 `AssetServer` handler 以同源 URL 提供本地 PDF 字节（支持 HTTP Range，大 PDF 按需读取），从架构上规避前端 pdfjs 双实例问题。
- **HTML 渲染安全边界** — `sandbox="allow-scripts"` 且不含 `allow-same-origin`，页面脚本可执行但处于 opaque origin，无法访问应用主页面与 Wails 绑定方法。同目录相对资源（css / js / 图片 / 字体）经后端 `/preview-raw` 白名单路由（扩展名白名单 + 绝对路径 + 普通文件校验）自动加载；渲染视图内相对链接面板内跳转、http(s) 外链用系统浏览器打开；支持「源码 / 渲染」切换（源码态可编辑保存）与刷新，超过 1MB 走超大降级提示。
- **就地编辑** — 文本类预览可一键切回编辑模式，保存复用既有 `SaveFile` 链路，并按原文件编码（UTF-8 / GBK）写回，不改变原编码；切换文件时自动检查未保存修改。
- **预览区复制** — 文本 / 代码 / Markdown 预览态下，鼠标选中内容可直接 `Ctrl+C`；右键菜单提供「复制 / 全选」（无选中文本时复制项禁用，全选走 CodeMirror 命令或 Selection API）。
- **行归属追溯（git blame）** — 源码预览右键开启「行归属」：每个 blame 连续块首行行尾标注「作者 · 相对时间 · 短SHA」，点击标注打开该文件提交历史并定位高亮对应提交（未提交行标「未提交」禁跳转）；行数超上限（10000 行）降级提示，JSON 派生视图（pretty-print 行号错位）不提供入口，与文件树「查看历史」衔接形成「仓库 → 文件 → 行」追溯闭环。提交历史 / 文件 diff 中的文件也可右键反向进入行归属（文件在工作树存在时联动预览自动开启标注，已删除文件自动转入文件历史追溯）。
- **Markdown 链接导航** — 相对引用（`./other.md`、`../readme.md`）在预览面板内切换；外部 http(s) 链接用系统默认浏览器打开；同文档锚点（`#标题`）滚动定位。拦截 `<a>` 原生顶层导航，避免误触后端 `AssetServer` fallback 返回 `{"error":"缺少 path 参数"}` 导致界面崩溃。
- **Markdown frontmatter 属性面板** — 文档开头的 YAML frontmatter 不再被当作普通正文渲染，而是解析为正文上方的结构化属性表格：数组值显示为标签徽章，标量值原样展示，嵌套对象以 JSON 文本呈现；解析失败时降级为带语法高亮的 YAML 原文代码块，不影响正文。
- **预览历史回退** — Markdown 相对链接跳转后，「后退」按钮可回到上一个预览文件；点击文件树节点（含同节点再点）始终重新加载预览，避免「链接跳转后预览体与选中节点脱钩导致空白」。
- **未知类型兜底** — 无扩展名或未知扩展名优先按文本读取（UTF-8 优先、GBK 兜底），可显示则降级为文本预览（可编辑保存）；含 NUL 字节或解码失败的二进制文件、超过 1MB 的大文件走降级提示。
- **降级为「用默认程序打开」** — 旧版 Office（`.doc` / `.ppt` / `.pptm` / `.pps`）、无 PowerPoint / WPS 环境下的 `.pptx`、损坏 / 超大 / 不支持的类型，统一提供「用默认程序打开」按钮。

### Git 集成

- **仓库信息与提交历史** — 查看提交历史（支持按作者 / 日期区间 / 文件路径 / 关键词服务端过滤，覆盖超过 500 条提交）、分支信息与仓库状态。历史采用纯内存缓存 + HEAD SHA 增量更新，避免重复扫描与 `getCommitFiles` 重算。文件树右键「查看历史」跨重命名追溯单文件演进（`--follow`），点击行归属标注可从预览直接跳入该历史并定位提交。
- **分支管理** — 创建 / 删除 / 重命名本地分支；`-d` 失败时二次确认改走 `-D` 强删；当前分支禁止删除。
- **切换分支 / 标签** — 「切换分支」弹窗按本地分支 / 远程分支 / 标签三组搜索选择；检出标签进入分离头（detached HEAD）状态并明确提示（此状态下的提交不被分支引用，切回分支即恢复），弹窗回显当前分离头引用且该标签置灰防重复切换。
- **变更与提交** — 双击变动文件弹窗双栏对照查看 diff；支持选择性提交（commit）与推送到远程（push）。
- **暂存区操作** — 单文件暂存 / 取消暂存（行级 `+/-` 按钮 + 批量「更多」下拉），统一使用 `git restore --staged`，通配已跟踪 / 未跟踪文件。
- **Stash 暂存管理** — 工作现场整体暂存到 stash（描述可自定义，勾选含未跟踪文件一并收存）；支持恢复（pop，移除条目）/ 应用（apply，保留条目）/ 删除；pop / drop 操作带确认弹窗，恢复冲突时条目按 git 默认语义保留并展示冲突文件清单与完整输出，冲突解决走「合并 / 变基」链路。
- **标签与远程** — 标签列出 / 创建（轻量 + 注释）/ 删除 / 推送单个与全部；远程仓库增删、fetch 可选 `--prune`、为当前分支设置跟踪上游。
- **合并 / 变基 / 拣选** — 合并支持 ff / no-ff / squash 三策略，合并前校验工作区干净；变基支持 `--continue` / `--abort` / `--skip`；支持单提交 cherry-pick；pull 入口可选 `--rebase` 模式。
- **冲突解决（第一期）** — 冲突文件列表 + 标记已解决（`git add`）+ continue / abort，不做内置三方合并编辑器。
  - 快捷选边：以当前 / 以传入为准，一键解决，二进制冲突同样适用。
  - 「内嵌解决」弹窗逐冲突块决策（用当前 / 用传入 / 两者 / 手动编辑），实时合并预览，按原编码写回。
  - 存在冲突时自动切到「合并 / 变基」tab 并显示红点角标。
- **提交历史 diff** — 展开提交详情后点击变更文件，查看该提交相对父提交的双栏 diff（root commit 对比空树呈现全增）；列表勾选两个提交可生成区间 diff，按文件分组双栏展示，二进制文件降级提示。变更文件标签与 diff 内文件名右键可「查看文件历史 / 行归属」：文件历史定位到所在提交（区间 diff 定位到区间终点），行归属按文件在工作树存在性自动分流，与预览行归属标注、文件树「查看历史」共同构成双向追溯网络。
- **分支同步摘要条** — 提交历史 header 展示分支名、`↑ahead` / `↓behind` 计数，提交行用 refs 标签标出本地 / 远程头所在 commit（本地 primary、远程 info、分离 HEAD danger，重合时同行共标）。
  - ahead 可一键推送（无上游时确认 set-upstream）；behind 提供 split 下拉拉取（默认 rebase，可切 merge）；fetch 刷新远程引用。
  - 操作成功后摘要与列表自动刷新；behind 基于上次 fetch 快照并标注时效。
- **仓库上下文与并发** — 选中 Git 工作目录即可在右栏查看仓库详情，左侧工作目录列表标记 Git 仓库；变更类操作按仓库路径串行化（同仓操作进行中时拒绝并提示稍后重试，跨仓并行，只读操作不受影响）。
- **子模块管理** — 查看列表、四色状态标签、detached 警告、初始化、更新（checkout / merge / rebase / remote 四模式）、添加、删除（三步清理）、detached 状态切换跟踪分支。
- **取消链路** — 批量拉取、克隆、合并 / 变基 / 拣选及冲突继续 / 跳过等长操作均支持取消（详见下方「批量更新」）。

### 仓库洞察

- **分支对比** — 活动栏一级入口（只读）：
  - 选择仓库（默认当前工作目录，可浏览切换）与 A / B 分支（本地 + 远程），支持一键交换。
  - 双列对齐提交表：两侧独有提交同行配对，按 hash → patch-id → 归一化 subject 三级匹配（patch-id 徽标即疑似 cherry-pick，merge commit 天然不误配）。
  - 统计条包含 merge-base 之下共同历史计数、2000 条上限明示截断、无共同祖先提示。
  - 分支差异文件树为两侧并集，支持状态着色 / 过滤、rename 新旧双路径、二进制识别、未变更文件默认隐藏（可开关显示）。
  - 支持双栏 / 统一 diff 查看器；点击提交行查看变更文件列表与单文件提交 diff；对齐表可按 hash / 主题 / 作者过滤。
  - 操作类功能（cherry-pick / 合并 / 变基）仍走既有 Git 面板。
- **仓库统计** — 活动栏一级入口，复用提交历史缓存聚合可视化（不重复扫描 `git log`）：
  - 提交趋势图：按日 / 周 / 月聚合，固定档位 7 天 / 30 天 / 90 天 / 1 年 / 全部，粒度随档位自动适配。
  - 活跃度热力图：类 GitHub 草地，最近一年按日，5 档色阶。
  - 贡献者提交数排名（按提交数降序）。
  - 超过 5000 commit 的仓库采样最近 5000 条并提示；基于 ECharts 按需引入渲染。
  - 页面顶部展示当前仓库信息条（仓库名 / 路径 / 分支 / 远程地址，复用仓库信息缓存）；工作目录与文件树右键「跳转仓库统计」可一键跳转（仅 Git 仓库节点）。
- **状态看板（全局）** — 活动栏一级入口，手动 pin 关注的核心仓库（不全局扫描，开源仓等不关注的不进看板）：
  - 一眼看清每个仓库的工作区改动数（干净 / N 处改动）、最后提交时间（相对时间，hover 显完整时间）、stash 数、未推送提交数（ahead）、未拉取提交数（behind）、分支与上游状态；失效路径 / 空仓库等边角降级显示「-」不阻塞整表。
  - ahead / behind 基于本地远程引用（上次 fetch / clone 快照）计算，看板不主动 fetch，behind 为相对上次 fetch 的近似值并标注时效。
  - 点击行跳转该仓（切工作目录 + 展开文件树定位）。
  - 双入口添加 pin：看板「添加仓库」弹窗跨工作目录批量勾选 + 工作目录 / 文件树右键「加入状态看板」单仓随手 pin；列表持久化到 `data/dashboard_pinned.json`。
- **批量更新** — 一键批量 pull 所有仓库，自动跳过未配置远程的本地仓库。
  - 进行中可「取消未完成」：终止在途 Git 进程、跳过未启动仓库，已完成仓库结果保留，取消行中性标注而非错误。
  - 单仓拉取 / 克隆，以及合并 / 变基 / 拣选、冲突继续 / 跳过等操作中同样提供取消入口，取消后可立即重试；`Abort`（中止）作为回滚手段不提供取消。

### 工具箱

活动栏一级入口，独占整个窗口区域（左侧功能清单 + 右侧内嵌工具内容，与 AI 面板等一级面板互斥，全程无弹窗）。共七项：

| 工具 | 能力 |
| ---- | ---- |
| 拷贝到 | 跨目录复制文件 / 文件夹，支持自定义目标名与只读属性处理 |
| 进程管理 | 按端口号或进程名检索本机进程（进程名 / PID / 端口 / 协议 / 连接状态 / 内存）；行内「停止」先请求进程自行退出，5 秒未退出或拒绝关闭则转强杀；「强杀」直接终止；可选连带结束子进程 |
| 端口占用 | 本机监听端口一览（一行一个端口，按端口号升序），行内终止复用同一停止链路 |
| JSON/YAML 工具 | 纯前端校验（错误带行号定位）、格式化（JSON 缩进 2 / 4 可调）、压缩与互转（多文档拒绝转换，注释 / 锚点转换前显式确认） |
| 环境变量 | 按来源分页只读展示（Windows 系统 / 用户 / 进程三级，Linux 仅进程级），支持按名称 / 值过滤与名称排序；敏感命名（含 TOKEN / SECRET / PASSWORD / KEY 等，大小写不敏感）默认打码、点击临时显示，复制始终为真实值 |
| hosts 文件 | 只读解析展示本机 hosts 行结构（IP / 主机名 / 行内注释，兼容 IPv6）；注释与空行默认隐藏可开关，未识别行灰色标注不丢弃；支持按 IP / 主机名过滤与复制单行 / 复制 IP |
| PPT 拆分 | `.pptx` 按页拆分为多个单页 PPT，详见下方 |

- **PPT 拆分细节** — 同名文件夹内按 `原名-页序号.pptx` 命名，母版 / 版式 / 主题 / 媒体逐字节保留，仅支持 `.pptx`。
  - 支持单文件与文件夹批量两种模式：文件夹模式递归扫描子目录并自动排除历史拆分产物，串行逐个拆分，单文件失败不中断，提供双层进度与成功 / 失败汇总清单，批量可取消且已完成保留。
  - 工具箱面板（路径输入 / 浏览 + 实时进度 + 可取消 + 结果列表）与文件树右键 `.pptx`「按页拆分」双入口；输出文件夹已存在时覆盖重生成。
- **进程保护** — 本应用自身进程禁止终止；系统关键进程需红色二次确认。

### 素材管理

活动栏一级入口的本地素材索引库。索引模式下仅在应用数据目录建索引，扫描 / 检索 / 缩略图链路不修改原始文件；就地替换为显式勾选强确认后的删源例外。

- **多素材库管理** — 新建 / 切换 / 删除，每库独立索引数据与标签体系。
- **扫描与索引** — 扫描根目录下 `.pptx` 增量建索引：修改时间 + 大小判变跳过未变文件；加密 / 损坏 / 权限不足单文件降级不中断批量；进度实时可见可取消，支持手动全量重建自愈。
  - 自动忽略 Office 临时锁文件 `~$` 前缀，历史误入库记录随扫描清理；解析失败原因随索引落库，统计行「解析失败」可点开清单查看原因并一键复制。
  - 纯 Go 解析幻灯片页文本 / 标题 / 演讲者备注，单页级索引。
- **检索** — 关键词全文检索（中文按字切分，可命中页内正文；文件名 > 标题 > 页文本 > 备注相关性加权）与标签筛选可组合；同一 PPT 多页命中聚合折叠（可展开 / 平铺），结果分页懒加载。
  - 幻灯片默认合并【页自身标签 + 归属文件标签】虚拟继承筛选，可开「仅使用幻灯片自身标签」关闭继承。
  - 检索工具行支持多维筛选（多级标签树多选 / 星级 / 修改时间 / 大小区间，可保存为具名检索条件随时调取）与排序（相关性 / 修改时间 / 星级）。
- **浏览与详情** — 画廊网格双视图（文件 / 幻灯片）+ 详情侧边栏：
  - 文件级：星级 / 备注 / 标签编辑。
  - 幻灯片级：业务备注 / 星级 / 独立标签编辑（文件标签继承只读展示，业务备注与解析自带的演讲者备注分区展示并命名区分）+ 一键溯源跳归属文件。
- **缩略图** — 扫描后自动生成小图缩略图（分辨率与缓存上限可在面板设置，PowerPoint / WPS 均支持），画廊真实缩略图滚动到可视区懒加载。
  - 详情侧边栏高清大图改为打开时按需单页生成（先显示小图后覆盖）；重建索引仅对内容变化的文件重导缩略图。
  - 检索命中幻灯片可一键打开原 PPT 并跳到指定页；生成失败回退占位并支持单文件重试；未检测到 PowerPoint / WPS 时自动降级为纯文本索引（检索不受影响）。
- **PPT 按页拆分** — 库级「拆分全部 PPT」批量 + 文件详情单文件双入口：
  - 产物落点三选一：就地替换（默认推荐，源文件移入系统回收站，单页产物以页序前缀命名作为独立素材进索引，须勾选不可逆强确认）/ 素材库缓存目录镜像源树 / 源目录（自动排除索引）。
  - 增量判定已拆未变自动跳过，源变更重拆先清旧页；单文件失败隔离不中断批量并汇总明细（已删除源 / 已回滚 / 源保留）；进度实时可见可取消。
  - 已拆分文件可从幻灯片详情「打开拆分单页」系统直开，无需 PowerPoint。
- **批量操作** — 选中条目批量打标签 / 批量修改评分。
- **元数据导出** — CSV 带 UTF-8 BOM 供 Excel 直接打开，或 Markdown + YAML 每页一卡供 Obsidian 直接使用；范围支持选中条目 / 当前检索结果 / 全库，路径口径可选库相对或绝对，导出可中止。
- **文件丢失与重链** — 文件详情可删除单个 PPT（磁盘物理删除并把索引转「丢失」态，标签 / 评分 / 页标注保留）。
  - 扫描发现源文件缺失时标记「丢失」并保留全部标签 / 标注 / 评分，源文件回归自动复活。
  - 详情面板「重新定位」经哈希校验恢复元数据，拆分记录同事务迁移（「打开拆分单页」入口在重链后仍有效）。
  - 工具行「维护」菜单支持路径前缀批量替换与清理丢失记录。
- **排除规则** — 按库配置排除文件夹 glob 与忽略后缀，保存即自动增量重扫；命中的已入库文件转「已排除」态，检索不可见但标注保留，放宽规则后复活；统计行非零时显示已排除计数。
- **备份与还原** — 顶部「备份」一键整库快照 + 重建索引；删除库前自动备份，每库保留最近 5 份。
  - 「还原」弹层按时间倒序列出备份，选份确认后整体覆盖当前索引与标注；删库前备份失败会升级为「无备份删除」强确认，防零恢复点误删。
- **素材购物栏** — 跨库页级收集：幻灯片卡 hover / 详情侧栏 / 全屏预览三处加号与选中批量加页，同页幂等去重。
  - 抽屉拖拽排序且顺序持久化到 `data/asset_cart.json`；跨库条目混装，来源行展示库名 / 文件名 / 页码；失效条目置灰可移除，点击溯源定位回素材库该页。
  - 「合并导出」按购物栏顺序一键合并为单一 PPT：基底注入式纯 Go 合并，每页母版 / 版式 / 主题整链保留，等价「保留源格式」；可取消长操作并带进度，失效条目跳过并在结果中报告，默认名自动预填，成功后可选择清空购物栏。
- **素材文件夹树** — 画廊左侧可收缩的真实目录树：
  - 点击目录递归过滤主区素材并显示递归 PPT 数徽标；头部「全部展开 / 全部收起」批量按钮，双击目录名切换展开收起（单击选中过滤语义不变）；排除 / 拆分派生目录带标记。
  - 目录管理：新增 / 重命名 / 文件夹级标签与备注标注 / 删除（非空确认）。
  - 拖拽移动：文件 Ctrl / Shift 多选或目录整体拖入目标目录，磁盘真实移动 + 索引路径 / 拆分记录（含产物落点 `output_dir`）/ 文件夹标注键同事务级联同步 + 排除规则双向翻转 + 自动增量扫描收敛；`replace` 单页产物须随其产物容器目录整体移动，不可单独拖动；跨盘 / 重名 / 移入排除目录或自身子树明确拒绝。
  - 节点右键菜单（命令项与「⋯」下拉同源，含「在资源管理器中打开」当前目录）。

### 浏览器访问

同一二进制将完整界面暴露为浏览器可访问页面：桌面模式默认同开 HTTP 服务（设置「网络访问」可关），`--serve` 为无头模式纯服务常驻。文件 / Git / 终端 / AI 任务全功能与桌面一致，适合本机其他浏览器与远程设备（远程建议 Tailscale / frp 等加密隧道）。

- **访问与认证** — token 认证（首启自动生成，设置页可查看 / 复制 / 重新生成）；多令牌管理支持按设备命名、撤销与过期；默认绑定 `127.0.0.1:36115`；支持 HTTPS（自签 TLS 证书）。
- **连接可见性** — 多设备连接数在桌面与浏览器两端即时可见；桌面端可展开逐连接明细（IP / 令牌名 / 接入时间）并踢出指定连接（对端可用同令牌重连；防重连需配合撤销令牌）。
- **审计日志** — 踢出、封禁 / 解封等动作留痕到 `data/web_audit.log`，桌面端「网络访问」可查看历史（按事件类型 / 时间窗过滤 + 分页，踢出行含操作者来源归因；浏览器通道不提供）。被踢端横幅提示「连接已被主机断开」后自动重连。
- **令牌封禁** — 令牌管理列表显示各令牌在线连接数，并支持临时封禁令牌（永久或限时自动解封）；封禁仅拒新连接，可勾选同时断开在途连接；撤销令牌自动清除其封禁记录。封禁 / 解封动作留痕审计日志，持久化 `data/web_bans.json` 重启后持续生效。
- **来源 IP 封禁** — 自动 + 手动双层：
  - 自动为被动防线：同一来源 IP 10 分钟内认证失败达 10 次自动临时封禁 5 分钟，反复触发时长翻倍递增至封顶；参数与可信网段 CIDR 白名单（NAT 共享出口等可信来源豁免，对已生效封禁追溯放行）均可在设置页调参；回环地址恒豁免，到期自动恢复并重新计数，自动封禁计数为内存态、重启清零。
  - 管理员可在桌面连接明细面板「IP 封禁」区块手动封禁来源 IP（永久 / 限时即时生效，覆盖在途自动封禁），持久化 `data/ip_bans.json` 重启持续生效；触发时桌面弹 toast 提示。
- **攻击源洞察** — 同网段多来源被封禁时给出网段封禁建议（一键预填、仍须管理员确认提交），并基于审计历史输出跨重启的攻击趋势视图（近 N 天各网段自动封禁时序分布、管理员处置次数、解封后再犯标记，回看窗口可在设置页调整，数据起点受审计日志轮转保留约束）；建议与趋势仅桌面端可见。
- 详见 [功能说明 · 浏览器访问](docs/功能说明.md)。

### 系统能力

- **用 Obsidian 打开** — 工作目录树 / 文件树右键菜单及操作面板「查看操作」均支持：文件夹以自身作为仓库（vault）、文件以父目录作为仓库。
  - 可在「设置 → 通用 → 外部应用」自定义 Obsidian 程序路径（配置后优先使用，否则走 `obsidian://` 协议 + 注册表预检 + `cmd /c start`，未检测到时引导用户配置或安装）。
  - 打开前读取 Obsidian 仓库注册表（`%APPDATA%\obsidian\obsidian.json`）判断目录是否属于已注册 vault；未注册时弹确认框引导跳转 Obsidian 仓库管理器手动添加（避免 Obsidian 弹出 "Vault not found"），注册表读取失败则降级为尽力打开。
- **打开资源管理器优先 tessoa** — 工作目录树 / 文件树右键「打开资源管理器」与内容面板打开按钮优先检测本机 [tessoa](https://tessoa.cn/)（跨平台文件管理器，支持分屏 / 预览 / 标签页）：
  - 可用则经 tessoa 打开目标路径（目录与文件均传原路径，文件由 tessoa 自行定位所在目录）；不可用或启动失败降级系统文件管理器（Windows 文件场景保留 `explorer /select,` 定位选中语义）。
  - 可在「设置 → 通用 → 外部应用」自定义 tessoa 程序路径（配置后优先使用，留空自动探测 `PATH` 中的 tessoa）。
- **检查更新** — 设置面板显示当前版本号，一键检查 GitHub Releases 新版本；下载进度实时显示并支持取消。更新完成后提示重启，可选择立即重启或下次启动时自动替换。

## 快速开始

### 环境要求

| 平台 | 运行要求 | 说明 |
| ---- | ---- | ---- |
| Windows | Windows 10+ | WebView2 运行时系统自带，零额外依赖 |
| Linux | Ubuntu 22.04+ / Debian 12+ | 桌面模式需 GTK3 与 webkit2gtk-4.1；浏览器访问模式（`--serve`）无额外系统依赖 |

开发环境通用要求：

- Go 1.26+
- Node.js 22.12+（前端依赖 mermaid 12 的 `engines` 硬要求）
- [Wails CLI](https://wails.io/docs/gettingstarted/installation) v2

### 开发

```bash
# 安装前端依赖
cd frontend && npm install

# 启动开发模式（热重载）
wails dev
```

### 构建

```bash
wails build
```

构建产物位于 `build/bin/`，Windows 生成 `workbench.exe`（当前约 43MB，含 pdfjs viewer 静态资源）。

Linux 构建需先安装桌面编译依赖（Ubuntu 22.04+ / Debian 12+）：

```bash
sudo apt-get install -y build-essential pkg-config libgtk-3-dev libwebkit2gtk-4.1-dev
wails build -tags webkit2_41
```

产物为 `build/bin/workbench`。`-tags webkit2_41` 将 WebKit 依赖从默认的 webkit2gtk-4.0 切换到 4.1（Ubuntu 22.04+ / Debian 12+ 仓库仅提供 4.1）。详见 [部署说明](docs/部署说明.md)。

### 运行模式

```bash
# 桌面模式（默认）：打开窗口，同时在 127.0.0.1:36115 提供浏览器访问
./workbench

# 无头模式：不开窗口，仅常驻 HTTP 服务（适合服务器 / 远程访问）
./workbench --serve

# 指定监听地址（优先级高于 settings.json 中的 webServe.bindAddress）
./workbench --serve --listen=0.0.0.0:36115

# 查看版本与构建时间
./workbench --version
```

首次启动会自动生成访问令牌，可在桌面端「设置 → 网络访问」查看、复制或重新生成。

### 发版

#### 一键发版（推荐）

使用 `scripts/release.sh` 一键完成「读取当前版本 → 递增 → 改写 `wails.json` → 提交 → 打 tag → 推送」，推送后由 CI 自动构建发布：

```bash
# 预览计划（不执行任何写操作）
./scripts/release.sh --dry-run --bump patch --allow-dirty

# 次版本递增并直接推送（如 1.0.9 -> 1.1.0）
./scripts/release.sh --bump minor --yes

# 手动指定版本号
./scripts/release.sh --version 1.2.3 --yes
```

也可对 Claude 说「发版」，或使用 `/release` 触发智能推荐流程：skill 会按 `$LAST_TAG..HEAD` 范围内的提交类型（`major:` / `feat:` / `fix:` 等）推荐 `patch` / `minor` / `major` 级别，确认后自动调用脚本。

#### GitHub Actions 自动打包发版（底层机制）

推送 `v*` 格式的 tag 即可触发流水线：

```bash
# 创建并推送 tag（例如 v1.15.0）
git tag v1.15.0
git push origin v1.15.0
```

流水线自动完成：

1. 在 Windows 与 Ubuntu 22.04 runner 上并行安装 Go 1.26 + Node.js 22 + Wails CLI（Linux 侧另装 GTK / WebKit 开发依赖）。
2. 执行 `wails build`（自动注入版本号与构建时间；Linux 侧叠加 `webkit2_41` 标签）。
3. 创建 GitHub Release 并上传 `workbench.exe`（Windows）与 `workbench-linux-amd64.tar.gz`（Linux，扁平布局：`workbench` 二进制 + `README-linux.md` 依赖说明，解压即用）。

> **CI 机制**：远程 `origin` 为 GitHub 主仓库（SSH：`git@github.com:hello007/workbench.git`，需已配置 GitHub SSH key），推送 commit 或 `v*` tag 即直接触发 GitHub Actions（`ci.yml` / `release.yml`），无镜像中转，无需配置额外 remote 或手动同步。

### 测试

```bash
# 后端测试
go test ./...

# 后端集成测试（真实 git 仓库 fixture，含 submodule 全链）
go test -tags=integration ./...

# 长跑稳定性深跑（soak + 泄漏断言，默认档已随 go test ./... 自动跑）
go test ./service/ -soak-rounds=2000 -run TestSoak -v

# 前端测试
cd frontend && npm test

# E2E 测试（Playwright + mock Wails 后端，首次需先 npm run e2e:install）
cd frontend && npm run e2e
```

### 测试覆盖率门禁

```bash
# 后端覆盖率门禁（分层阈值：model/server ≥80%，service ≥76%，util ≥40% 且排除 pty_windows.go）
bash scripts/coverage-check.sh

# 前端覆盖率（vitest v8 provider + thresholds，低于阈值 exit 非 0）
cd frontend && npm run test:coverage
```

详见 [测试策略](docs/测试策略.md)。

## 项目结构

```text
.
├── main.go                 # 主入口（桌面 / --serve 双模式装配）
├── app.go                  # 应用结构体与基础桥接
├── app_*.go                # Wails 桥接层，按业务域拆分（目录 / 文件 / Git / 素材 / AI / 网络…）
├── app_services.go         # AppServices 装配（service 实例集中构造）
├── model/                  # 前后端契约数据模型（签名与字段变更需同步 wailsjs）
├── service/                # 业务逻辑层（Git、终端、素材索引、AI、审计…）
├── util/                   # 工具层（git 命令封装、原子写、编码、日志…）
├── server/                 # 浏览器通道：HTTP RPC / WebSocket / 令牌 / IP 封禁 / 自签 TLS / PDF 预览 AssetServer
├── frontend/
│   ├── public/
│   │   └── pdfjs-viewer/   # pdfjs 官方 viewer 静态资源（go:embed 打包）
│   └── src/
│       ├── views/          # Home / BranchCompareView / DashboardView / StatsView
│       ├── store/          # Pinia setup store（6 个：favorites / directory / workspace / ui / settings / aiChat）
│       ├── composables/    # useTerminal / useTerminalTabs / useCommandPalette / useTreeState / useSessionState 等
│       ├── components/     # 面板与业务组件（Git / 素材 / AI / 工具箱 / 终端 / 设置 / 对话框）
│       ├── transport/      # 双通道收口：桌面 Wails 绑定 / 浏览器 WS + HTTP RPC
│       ├── utils/          # 前端纯函数工具（diff 解析、树截断、冲突标记、编码还原等）
│       ├── router/         # Vue Router
│       └── wailsjs/        # wails generate 生成产物，不入库
├── data/                   # 运行时数据（索引库、配置、日志、缓存，不入库）
├── docs/                   # 项目文档（spec/ 深度契约、memory/ 长期记忆、agent-resources/ 通用资料）
├── scripts/                # 发版、覆盖率门禁、依赖一致性、性能基线等脚本
├── build/                  # 构建资源与产物（bin/、windows/、linux 说明）
└── wails.json              # Wails 配置（版本号真相源）
```
